# probes

Tools that talk to Google, for checking things by hand.
Run from `work/`, for example `python3 probes/render_deck.py ID`.

| File | Does |
|---|---|
| `p0_api_probes.py` | the API experiments the ownership rules rest on |
| `p0_ui_probe.py` | the same for edits made in the browser |
| `render_deck.py` | export a deck as PNG pages to `/tmp/gcheck` |
| `human.py` | imitate a person editing a deck |
